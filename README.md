# ⚖️ BMI Calculator

A Flutter application that calculates Body Mass Index (BMI) based on user-provided height and weight.

## 📌 About the Project

BMI Calculator is a beginner-friendly mobile application built to practice Flutter UI development, user input handling, and mathematical calculations.

The application calculates BMI and displays the resulting value.

## ✨ Features

- ⚖️ Calculate BMI
- 📏 Enter height
- 🏋️ Enter weight
- 📊 Display BMI results
- 📱 Simple mobile interface
- 🎨 User-friendly design

## 🛠️ Technologies Used

- Flutter
- Dart
- Material Design

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/natanim-samuel/BMI_Calculator.git
   ```

2. Navigate to the project:

   ```bash
   cd BMI_Calculator
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## ⚠️ Disclaimer

This application is intended for educational purposes. BMI is a screening measurement and does not provide a complete assessment of health.
